# 语言切换

顶部提供日本語 / 中文 / English 原生下拉选择，桌面和手机均可使用。默认日语，选择保存在当前浏览器的 `caba-language` 中；刷新后恢复，切换时不跳转、不丢失筛选条件。

- `src/i18n.ts`：响应式语言状态、界面文案与动态计数翻译。
- `SiteHeader.vue`：语言选择器；`DesignNode.vue`：按语言展示设计节点文字，保留内部原始值及行为映射。
- 导航、首页搜索、主要列表/详情标题、操作按钮、筛选标签、空状态、加载/错误提示、联系弹层和页脚使用界面翻译。使用指南与 FAQ 的主要文案也已提供翻译。
- 搜索选项展示翻译文本，但提交原始地区 ID 和字段值。语言切换不改变后台实体 ID、URL、收藏或图片。
- 店铺名、Cast 姓名、地区名称和后台录入的介绍保留原文；尚未收录的文案回退原文。没有请求外部机器翻译服务。
- HTML `lang` 随选择设为 `ja` / `zh-CN` / `en`。

验证：三种语言即时切换；英文刷新后保持；在 `/casts?area=33&shop=vanilla` 切换中英文仍保留查询参数和 2 位 Cast 结果；320px / 375px 顶栏与页面宽度检查；TypeScript 和生产构建通过。
