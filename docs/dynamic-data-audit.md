# 非支付动态数据接入检查

检查日期：2026-11-09。对照当前 Vue 页面、现有后台代码，并在 Web 浏览器中实际 GET 公开接口。此次为检查及规划，没有新增业务提交或修改后台数据。

## 已接入

首页店铺/Cast、店铺/Cast/Plan 列表与详情、相册、地区树与筛选、店铺推荐页。收藏页展示真实记录，但收藏关系仍保存在本地浏览器。首页搜索栏右侧保留用户指定的固定默认图。

| 内容 | 来源 | 现状与接入位置 |
| --- | --- | --- |

| 使用条款 | `GET /api/cabakura_terms/lists?name=利用規約` | 实测 1 条且有正文，可替换 `/legal/terms` 设计示例正文。 |
| 隐私政策 | `GET /api/cabakura_terms/lists?name=プライバシーポリシー` | 实测 1 条且有正文，可替换 `/legal/privacy` 设计示例正文。 |
| Cast 排班 | `GET /api/cabakura_home/castSchedule?cast_id={id}` | 接口支持 from/to，返回日期、起止时间和出勤状态；Cast 详情可增加出勤日历。抽查 Cast 1 当前返回 0 条，应显示未公布，不能填造排班。 |
| 店铺营业状态与 Cast 状态 | `index` / `detail` 现有字段 | 营业状态可增加到店铺卡片/详情；Cast 新人、热门、推荐等标记可增加到卡片。部分出勤状态已在公开资料里显示，日历尚未接。 |

| 网站基础配置 | `GET /api/index/config` | 有网站名、Logo、favicon、版权配置。实测名称为“Caba Night総合管理画面”，版权数组为空，不适合直接覆盖消费者 Web 的 CABA NIGHT 品牌，需要先区分管理端与 Web 品牌配置。 |

条款/文章等 HTML 富文本接入时需清理内容，并正确处理正文中图片的域名。

## 接口存在，但需要登录或业务整理

| 内容 | 现有能力 | 前置工作 |
| --- | --- | --- |
| 云端收藏 | `/api/cabakura_favorite/lists`、`toggle` 及 Cast 对应接口 | 需要 Web 会员登录；现有接口支持店铺与 Cast，尚无 Plan 云收藏接口。不能直接用后台管理账号作为 Web 会员身份。 |
| 客服咨询与纠错 | `/api/cabakura_support/latest`、`send`、`read` | 需要会员登录。可接平台联系/纠错页面到后台客服工单；如允许游客提交，需新增游客入口、分类/对象字段及必要的提交限制。 |
| 优惠券展示 | `/api/cabakura_coupon/lists` | 当前是会员优惠券，需要登录并厘清适用于纯信息 Web 的展示/领取规则；这不必接支付，但不能直接当作公开优惠列表。 |
| 专题、指南、FAQ、关于平台 | `/api/article/cate`、`lists`、`detail` 为公开接口 | 实测分类为“好物/生活/科技”，文章为脚手架通用内容，当前不能作为 CABA NIGHT 专题直接发布；需新增合适分类并录入正式内容，或建立专用内容管理。 |

## 需要补后台公开字段或内容模块

- 商家电话/邮箱：管理端已有字段，当前公开 shop detail 不返回。需确认哪些是对外联系信息后补充公开字段。
- 商家 LINE/官网、Cast Instagram/X/TikTok：当前读取到的 Shop/Cast 资料维护逻辑及公开接口没有这些完整链接字段；需增加后台编辑、存储及公开输出，随后 Web 才能真实跳转。
- 正式活动、优惠信息：当前 Web 活动/优惠页仍为设计示例，未找到独立的活动公开接口；需维护标题、正文、封面、关联店铺、开始/结束日期与发布状态。可共用新闻/文章模块，但需要先明确字段及分类。
- 地区介绍、地区封面、交通介绍：地区树目前有名称、层级及排序，没有独立运营文案/封面；现有地区图使用关联店铺图片。若需要后台独立维护，应补字段。
- 品牌介绍、平台联系方式、商家入驻说明：现有 Web 页面仍是设计内容；需要正式配置字段或内容分类后接入。
- 真实更新时间、完整分页、稳定套餐 ID：公开目录有 50 店铺/200 Cast 上限，套餐仍用数组下标；若持续运营，宜补分页、更新时间及稳定套餐 ID。

## 建议顺序

1. 新闻/公告、使用条款、隐私政策：已有正式维护入口及公开数据，接入成本较低。
2. Cast 排班、营业状态、联系人与社媒：完善浏览后联系商家的核心路径；其中联系人/社媒先补后台公开字段。
3. 正式专题/指南/FAQ 内容，以及平台联系/纠错。
4. 需要会员时再加登录、云收藏、客服工单和会员券。

支付、订单、退款、订阅和站内预约不在上述建议范围内。
